# 轨迹 - 铁路出行规划

## 项目介绍

“轨迹”是一款面向铁路出行的行程规划工具，提供 Web 页面和适用于小米澎湃 OS / Android 的本地安装包。它可以按日期查询 12306 实际车次，也可以使用社区静态时刻表离线规划；支持多组出发站、途经站和到达站，以及直达或最多 3 次换乘、时间区间、车次类型和换乘时长筛选，最终以时间线形式展示候选行程。

项目采用本地优先的设计：路线计算在运行服务的设备上完成，12306 查询仅进行有界、只读的数据获取，不包含登录、购票或抢票功能。核心规划器、命令行、Web UI 与 Android 应用共用同一套数据模型和搜索逻辑。

## 小米澎湃 OS / Android 安装包

适用于 Android 7.0（API 24）及以上的 64 位 ARM 手机。应用申请联网权限以及后台规划所需的前台服务、通知权限，所有时刻数据和规划缓存都保存在应用私有目录；首次启动可直接使用 APK 内置的当前静态数据，界面会随系统深色模式自动切换。

手机端默认开启“允许后台静默搜索”：从应用内开始自动规划后，可以切换到其他应用，低打扰的前台服务会维持本次查询；进行中的通知以本次启动时间加预计耗时显示 24 小时制的“预计 HH:mm 完成”，跨越午夜也只显示钟点。规划成功时原通知更新为方案数量，规划失败时更新为简短原因，点击终态通知均可回到应用。Android 13 及以上首次使用时需要允许通知。强制停止应用、清除后台进程或关闭通知权限时，无法保证继续查询或弹出完成提醒。

将 APK 传到手机后点击安装。如果澎湃 OS 阻止安装，请只为当前文件管理器或浏览器临时允许“安装未知应用”。这是 debug 签名的个人安装包，不需要应用商店或小米开发者账号。安装后打开“轨迹”即可；联网时可查询 12306 并检查 GitHub 静态数据更新，断网时仍可使用内置静态时刻表。

APK 的 SHA-256 保存在同目录的 `.sha256` 文件中。

## 同步 12306 数据（实验性）

12306 网页接口没有公开的版本稳定性承诺，因此实时适配器和规划器相互隔离。同步命令只执行 GET 查询，不登录、不处理验证码，也不包含购票能力。

同步结果的 `metadata` 会记录数据时间、是否来自缓存、是否使用过期缓存，以及城市对应的车站集合。默认最小请求间隔为 1 秒，最多展开 24 个站点对；网络失败时可回退到通过结构校验的旧缓存。

实时查询可能因官方接口变化、限流或临时网络故障而失败。错误页和登录页会被识别为数据源错误，不会显示成“没有车次”。查询结果仅供参考，准确信息以铁路车站公告为准。
